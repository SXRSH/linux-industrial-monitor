# Linux-Based Industrial Equipment Monitoring and Fault Detection System

## Project Overview

A Linux-based industrial equipment monitoring and fault detection system implemented using C/C++ and a custom Linux character device driver.

The system monitors industrial equipment parameters such as temperature, vibration, motor RPM, voltage, and current. It identifies abnormal operating conditions and generates appropriate warnings or critical fault notifications.

## Objectives

- Monitor industrial equipment parameters.
- Implement a custom Linux character device driver.
- Demonstrate communication between user space and kernel space.
- Detect abnormal operating conditions.
- Implement fault severity classification.
- Provide event and fault logging.
- Demonstrate Linux system programming and embedded software architecture.
